# 桌面与书签整理专员（第一版）

## 使用与边界

- 「桌面与书签整理专员」右上角的开关与其他数字员工一样控制后台巡检，默认关闭。打开后按设定间隔和每日上限生成待审批提案，可能向已配置的模型发送下方所列样本；关闭后仍可手动生成。
- 也可在预览窗点击「重新盘点提案」。生成提案不修改桌面网站或浏览器书签；员工配置、快照和提案记录会保存在扩展本地存储。
- 左侧有「已生效状态」「整体提案」「悬停单步（含前置）」三种模拟视图。均基于该次盘点快照，不是实时浏览器镜像；历史提案不混用其他运行的快照。
- 右侧点击一个任务，只执行该任务。提案优先使用现有文件夹，也能给桌面和书签的文件夹、链接改名。移除文件夹时将内容移到上一级；合并则移到指定目录。浏览器书签目录的移除和合并不提供撤销。
- 保留「全部生效」：点击后需在窗内再次确认，按原顺序逐步执行待审批/可重试的校验失败项；跳过项不执行，遇到错误立即停止。已经确认的步骤不会自动回滚，也不承诺整批原子性。
- 大 / 紧凑是两档实际尺寸。旧 `medium` 值兼容为 `small`；父子文件夹是层级关系，不是第三档布局。
- 窗口无遮罩，复用 SDK 拖动；空白外点或 Esc 收起。执行写入/批量审批期间不能关闭，避免误以为关闭代表取消写入。

## 模型输入与隐私

- 模型收到完整分区列表，以及前 60 个网站、40 个桌面文件夹、80 条书签、30 个书签目录；预览窗显示盘点总量和模型样本数量。不是全量语义整理。
- 发送样本标题、目录名称/路径、对象 ID、归属关系、少量审批偏好和公网 origin。URL 的路径、查询参数、片段与用户凭据不发送；本地、内网形式的地址隐藏。数据文本中的 HTTP(S) URL 同样经过裁剪。
- 标题和目录名称本身仍可能含私人信息，不能将 URL 裁剪称为彻底匿名化。用户自定义提示词属于用户主动配置的模型输入。
- 本地/原生模型入口也可能使用其配置的远程供应商，不承诺数据不离开设备。未配置可用模型时仅提供有限域名规则提案，不声称完成全量整理。
- 真实 URL 仅保留在本地快照，执行时按已有对象 ID 重读；模型不能用虚构书签网址创建桌面项。

## 写入与撤销

- 拒绝同名覆盖、自身嵌套、循环父级、不匹配的目标分区；浏览器现有重名目录必须用唯一 ID 定位，新目录使用浏览器返回的 ID。
- 执行前重读并核对源网站/书签的地址、名称、原位置及目标归属；旧版无安全引用的提案必须重新生成。
- 写入前先持久化执行中状态与撤销凭据。浏览器回收后台、响应丢失或写入后日志保存失败时，保留「结果未确认」并拒绝重复执行该提案，用户须核对实际数据后重新盘点；不将错误当成“肯定未写入”。
- 可逐步撤销仍保留运行记录的已确认操作。运行日志最多保留120条，清空历史、删除员工或记录被淘汰后不能再依赖此入口撤销；请先处理待审批/撤销需求。先撤销依赖步骤；撤销会核对当前对象，不覆盖后续手动修改。新建书签目录仅在仍为空、名称和父级未变时才能删除；不存在自动删除用户原有书签的整理动作。
- 网站撤销只还原该条对象并保留其他网站；分区/文件夹撤销对相关存储键做保守冲突检查。没有强制覆盖式“整轮快照恢复”；可逆序逐步撤销，遇冲突应先核对。
- Web Lock 只协调遵守同一锁的桌面写入者。浏览器原生书签 API 没有事务，其他页面、同步或用户同时编辑仍可能在检查与写入之间竞争；本版不能提供全浏览器原子性或崩溃后的自动回滚保证。
- 审批和跳过记录本条建议的保留/跳过反馈，恢复待批/撤销时移除对应反馈。只是有限偏好输入，不代表训练模型、推断真实访问频率或自动学习已验收。

## 验证

`tests/workspace-organizer.test.mjs` 使用纯内存数据覆盖安全边界、稳定引用、模拟预览、冲突、撤销、隐私输入、后台审批与未确认写入防重；`tests/digital-employees.test.mjs` 保留原审批流程回归。

类型、构建和离线测试不等于真实书签/模型接口或主题布局验收。未自动打开浏览器、刷新扩展、读取用户真实书签或调用真实模型；需用户自行刷新并用可丢弃数据验收。

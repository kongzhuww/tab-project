# GitHub Star 本地分类与使用手册说明

## 1. 范围与数据归属（已按用户要求切换为纯本地分类）

- **收藏数据源**：依然从 GitHub 官方接口读取用户的 Star 列表（支持未配置 Token 时读取公开 Star，配置 Token 时提高速率额度）。
- **分类与分组完全本地化**：
  - 新建分组、删除分组、将仓库拖入分组、移出分组以及右键“移到未分组”，均仅在本机浏览器的扩展本地存储（`chrome.storage.local`）中持久化，键名按当前账号隔离：`ghLocalStarGroupsV1:<cacheKey>`。
  - **绝不发起 GraphQL `updateItemLists`、`createList` 或 `deleteList` 请求**，不再修改用户的 GitHub 官方 Lists。
  - **一次性安全平滑迁移**：首次加载时，若本地存在旧版的官方 Lists 缓存，会自动作为本地分组的初始数据导入，保留已有分组与归属，避免用户重头整理；原有缓存不会被覆盖或删除。
- **文案与描述全面对齐**：
  - 侧边栏标题更新为“**收藏分组**”，副标题更新为“**读取 GitHub 收藏 · 本地分类**”；
  - 页面顶部描述更新为“**X 个 GitHub 收藏 · 分组仅保存在本机**”；
  - 移除了所有“云端实时同步”、“GitHub 列表”等可能产生误导的描述。

## 2. 交互与布局优化

- **删除未分类托盘下方的重复搜索框**：
  - 未分类托盘右侧原有的内联小搜索框已彻底移除，顶栏保留分页器 `[ ‹ 1 / N 页 › ]`、刷新按钮与展开/收起按钮。
  - 搜索功能完全统一至顶部首屏的大搜索框（支持本地/全网切换及精确/宽松/近义词/标签匹配模式），搜索词通过 `starBoardData.searchQuery` 响应式驱动整个 Star 看板与托盘。
- **左栏“全部 / 未分类”与拖拽提示条已清理**：
  - 移除了左侧占用空间的纯文本导航行，保留清晰开阔的 2 列图标网格。
- **引入统一的翻页说明书（GitHub 使用手册）**：
  - 在左侧分组栏的标题右侧新增「`?`」手册按钮（与常用网站的帮助入口风格完全一致）。
  - 点击弹出 **GitHub 使用手册**（纯血无模态、100% 实心纸面、双页立体装订与翻页动画），包含四篇核心指导：
    1. 《数据边界 · 收藏从哪里来？》
    2. 《本地分组 · 像常用网站一样整理》
    3. 《效率技巧 · 快速找到有用的仓库》
    4. 《真实边界 · 哪些操作会改变什么？》
  - 说明书支持点击外部收起、右上角丝带关闭、Esc 键快捷收起以及键盘左右箭头翻页。

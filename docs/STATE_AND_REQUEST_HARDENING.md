# 状态同步与请求边界改进

## 本轮范围

仅修改桌面扩展源码，不变更权限、不改聊天服务器、不操作真实账号、不自动刷新浏览器。版本暂保持1.0.3，未提交或发布。

### Todoist 跨页面失效

- `todoist/change-channel.ts` 在同扩展origin的localStorage保存单条版本标记，storage事件通知其它页面；visibilitychange/pageshow补读最新标记。
- 标记只含协议版本、带领域前缀的Token SHA-256范围摘要、随机版本号；不包含原始Token、任务标题/正文。摘要不是认证凭据，也不是加密承诺，不应作为公开诊断数据导出。
- 通用Todoist API的非GET/HEAD请求获得成功HTTP响应后，本页失效工作区缓存并发布标记；JSON解码若随后失败仍按未确认结果提示，不重试写入。账号不匹配的消息忽略，不重播远端写操作。
- `use-task-invalidation.ts` 合并150ms内刷新，覆盖Todoist看板、任务日历侧栏、GitHub关联任务。隐藏或本页有写入时保留待刷新状态，恢复可见/写入结束再读取。读旧会话取消不影响POST。
- 只重新读取当前视图及已关联任务，不通过推送数据直接覆盖编辑器草稿。不是全账户同步引擎，不是跨设备推送；在Todoist官网/其它设备修改仍需手动刷新或现有读取触发。
- 单条持久标记用于避免后台冻结遗漏通知，不承诺消息日志或跨账号并发的恰好一次。localStorage不可写时保留远端操作结果并记录不含凭据的警告，其他页面需手动刷新。

### 后台媒体处理

- `background/media-fetch.ts` 提供15秒请求+响应体读取预算、12MiB实际字节限制（不只相信Content-Length）、最多2个图片处理任务。只接受无内嵌凭据的HTTP/HTTPS地址，拒绝重定向，不再尝试HTTPS降级HTTP。
- 图片支持PNG/JPEG/GIF/WebP/AVIF；未知类型不再默认冒充PNG。Base64输入和AVIF转PNG产物同样有12MiB限制。
- 尺寸上限为24*1024*1024像素、单边16384；PNG/GIF在解码前读尺寸头，其它格式解码后检查并释放bitmap。**这不是所有格式的解码峰值内存硬隔离，也不限制动画总帧数**。浏览器解码/编码耗时不同于网络15秒预算。
- AVIF转换失败明确失败，不返回伪标记PNG。需登录或跨站跳转的图片可能不能通过该无凭据代理读取，应提示失败，不用无上限下载兜底绕过保护。
- 删除downloadBiliVideo的全视频arrayBuffer/Base64备用路径；由浏览器下载管理器接管，创建失败就报错，不自动重发。DL只表示下载已创建，不表示文件已完整落盘。B站已有用户目录流式缓存链路未修改。
- 本轮仅收紧后台saveToFavorites/fetchImageForClipboard及downloadBiliVideo，不声称所有前端图库、图片搜索、第三方网络请求均已统一限额。

### Todoist 结构化错误

- `todoist/api-error.ts`：kind、status、retryAfterMs、submitted；区分配置、鉴权、限流、资源不存在、网络、超时、取消、数据格式和其它HTTP错误，不解析错误字符串判断401/403。
- 通用api()对429读取Retry-After秒数/HTTP日期，缺省60秒；在当前页面、当前Token范围内阻止冷却期新请求，不定时自动重试。其它已经发出的并行请求不会被伪称撤回，跨标签不共享冷却时钟。
- 任务filter兼容回退仅在404/410资源不存在时进行；鉴权、限流、网络故障不再连发多种备用查询。
- 关联卡、Todoist看板、日历侧栏接入明确错误提示；看板使用旧缓存时同时带瞬时读取警告，不伪装刷新成功。完成操作未发出与已发送未确认分开，不自动重试。
- 这是Todoist通用API及主要读取UI的迁移，不将上传专用接口、其它平台请求器或所有编辑表单宣称已全量迁移。

## 人工验收清单

1. 两个扩展页面分别打开Todoist和同仓库任务；完成/编辑任务后另一页更新。后台页面恢复可见后更新，正在编辑的详情草稿不被替换。
2. 连续修改、切换视图、隐藏再打开，核对无持续刷新、无旧请求覆盖新视图；循环任务允许出现下次实例。
3. 账号切换后旧账号写请求迟到，不应用到新账号页面；不导出或展示Token/范围摘要。
4. 普通PNG/GIF/JPEG/WebP及AVIF复制/保存；超过12MiB、超大PNG/GIF、坏文件、重定向地址、断网应明确失败。超过2个并发图片操作提示繁忙，不排无限队列。
5. 视频创建下载后在浏览器下载管理器核对完成状态；失败不出现第二次整视频读取。
6. 401/403、429、超时、断网、404各自提示；429冷却期手动刷新不再发出新请求，冷却后仍需用户或正常读取触发。缓存已显示时失败提示仍可见。

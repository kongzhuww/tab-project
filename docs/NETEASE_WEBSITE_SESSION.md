# 网易云官网会话接入

## 使用方式

在网易云模块点击“官网登录”，在同一浏览器、同一用户资料中完成官网登录，再回到扩展点击“连接官网账户”。无需本地 localhost:3000 或公共代理节点。扩展需要保留对 https://music.163.com/ 的网站访问权限。

## 请求与数据边界

- src/music/official-api.ts 仅允许固定的网易云 HTTPS 来源与只读路径，浏览器通过 credentials: include 附带官网会话。拒绝重定向，不读取或复制官网 Cookie，不向第三方节点发送凭据。
- 不再使用旧节点设置、旧扫码接口或第三方二维码图片服务。已有旧 neteaseCookie 存储不迁移、不自动清除，也不参与新请求。
- 账户资料、歌单缓存仍为浏览器本地数据。点击连接会重新核实官网账户并清除旧账户的歌单缓存。
- “退出登录”按钮仅断开扩展，保留官网会话；它不是从网易云网站全局注销。
- 账户、歌单、歌单已返回的曲目、搜索、歌词和歌曲地址接入只读适配。歌单曲目可能不全，歌曲地址仍受付费/版权及官方接口限制，不能绕过。
- 点赞写入、云端历史与排行榜聚合尚未接入这套官网适配，未接入操作明确报错，不偷偷回退代理。浏览器本地最近播放记录不受此限制。

## 验收边界

这些是非官方公开承诺的网页接口，可能变更或受风控。官网可登录不保证扩展请求一定获准，第三方 Cookie/浏览器策略也可能影响会话。类型检查和构建不代替全面验收；用户已确认“连接官网账户”点击后成功。其余接口及跨浏览器行为未全面验收；助手未自动打开或操作用户浏览器，未读取真实 Cookie。此实现纳入本次 1.0.0 同版本重发，实际发布结果以 Release 附件及 build-info.json 为准。

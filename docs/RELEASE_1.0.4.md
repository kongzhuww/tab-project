# tab-project-next v1.0.4

本次更新聚焦 B站电台防覆盖与智能切源、WebDAV 漫游支持电台系列、全仓三层文档架构重构与权限说明补充、YouTube 推荐胶囊视觉优化、清理废弃构建块。

## 更新内容

### B站电台与播放链路
- **电台保存防覆盖保护**：彻底移除空名时自动取收藏夹名并静默覆盖现有同名系列的隐式逻辑。保存系列未输入名称时，严禁提交并触发红色边框抖动与焦点聚焦提示。
- **智能切源与播放防卡死**：遇到超时、网络错误、鉴权/限流异常时立即终止无效重试，支持最多 3 次自动切换备用音视频源；小窗与剧场模式均接入多源故障转移。
- **并行 CID 预解析与流控**：对已有 CID 的视频并行获取详情与播放地址；切换视频时立即取消旧请求，彻底修复关闭播放器后后台音频持续播放的泄漏问题。

### WebDAV 同步漫游
- 同步载荷增加 `bili_radio_custom_series` 字段，自定义电台歌曲系列完整纳入坚果云/私有 WebDAV 云端备份与一键跨设备恢复。

### YouTube 卡片视觉与交互
- 移除顶栏冗余的“已重新读取收藏”横条提示，保持界面清爽。
- 重构左侧个性推荐为优雅的浅紫渐变卡片与药丸胶囊徽标（`FOR YOU · 猜你喜欢 · 每次刷新`），严格契合全站主题规范。

### 文档三层体系重构与清晰定位
- 建立三层架构：`README.md`（面向使用者）、`docs/CURRENT_STATE.md`（面向开发者入口）、`docs/MODULE_INDEX.md`（现行模块全量索引）、`docs/history/`（历史台账归档）。
- `README.md` 收敛核心定位，建立核心功能 vs 可选扩展服务的 4 级状态与使用条件矩阵；补充 manifest 各项权限申请原因与数据流向隐私说明。
- 统一全仓主题正式名称：确立 4 套正式界面主题（白天 `light`、夜晚 `dark`、终末地 `endfield`、孤星 `lonetrail`），明确区分开机启动动画（莱茵生命 `rhinelab` / 终末地 `endfield`）为独立设置。

### Native 历史命名残留清理
- 彻底清理后台注释中的 Native Messaging 残留描述；
- 将 `cleanupOrReplaceNativeNewTabs` 更名为准确的 `cleanupOrReplaceBrowserDefaultNewTabs`，保留历史兼容别名并明确标注其指代浏览器系统默认空白页（`edge://newtab` / `chrome://newtab`），与已移除的 Native Host 完全解耦。

### 工程构建产物瘦身
- 运行 `npm run clean:chunks`，自动清理 847 个历史废弃 chunk，构建包体积与代码组织更加干净整洁。

## 下载与升级

下载附件 **tab-project-v1.0.4-extension.zip**，不要使用 GitHub 自动生成的 Source code 压缩包作为扩展安装包。

升级前备份重要数据。沿用原扩展目录与浏览器资料更新文件，再由用户在扩展管理页重新加载，并刷新已打开的新标签页及独立模块页面。不要为升级随意卸载扩展或清除浏览器数据，以免丢失本地记录与授权。

另附 SHA256SUMS.txt 与 build-info.json，用于校验文件和构建来源。GitHub发布不会自动提交Edge商店；商店安装用户需等待另行提交、审核和分发。

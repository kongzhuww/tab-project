# 聊天室本地历史与待发队列

> 对应当前 HTTP 私有聊天室。源文件：`chat-history.ts`、`chat-delivery.ts`、`private-chat-client.ts`、`ChatHistoryTools.vue`。不按旧 P2P 回执或旧缓存恢复界面推断当前行为。

## 存储与读取

- IndexedDB `lw-chat-history` 当前版本 2，包含 `messages` 和 `relay-cursors`；消息主键为 `[scope, id]`。
- scope 由 UID、会话 endpoint、父房间生成；子 channel 位于 endpoint 中，不同身份/服务器/子房间不能共用历史。
- `commitRelayPage()` 在同一事务保存同步消息并推进游标。不能先推进游标、再假设消息肯定写入成功。同步页现先完整校验目录/名单/好友等草稿，再进入该事务，避免后半字段坏了却已推进消息游标；当前会话状态应用与非回滚边界见 [CHAT_SYNC_PAGES.md](CHAT_SYNC_PAGES.md)。
- 默认历史分页大小为 200 条，不是整个数据库的淘汰上限；“加载更早消息”读取同 scope 的更早记录。
- `chat-delivery.ts` 保存独立待发状态；消息发送前先归档/入队，再向服务端提交。服务端 `stored` 确认是落盘确认，不是成员接收或已读。重试绑定原目标；不能宣称无限离线投递或 exactly-once。
- 本地历史写入失败时显示错误和待存数量，提供重试。尚未成功写盘的内容可能仅在内存，关闭/刷新会丢失。

## 图片消息

- 文件选图、截图粘贴与同图库选择已接入受限图片消息：PNG/JPEG/GIF/WebP、原字节最多1MiB，较大静态图压缩，超限动图拒绝。服务端必须同时部署 server.py/image_policy.py 并返回 imageMessages=1，不能只更新前端。
- 图库只索引磁盘原图；**发送后，图片数据会作为消息进入本地历史、待发队列和服务器数据库**，这与图库导入是不同的存储行为。落盘回执后待发记录释放图片载荷，只保留确认元数据；本地聊天历史仍包含图片。
- 本地入队失败或服务端不支持时不清空待发图片；切房/隐藏时迟到的图片处理不改投新房间。已暂停的旧失败图片不批量自动补发，由用户在原消息详情中选择重试。
- 已获准完成现有服务的代码/SQLite一致性备份、部署和重启，回环及HTTPS代理健康检查返回图片能力；这不替代真实双端发图/动图/断网恢复验收，未操作用户浏览器或照片。

同步与发送协调现已拆分，原历史/队列数据库与事务不变，详见 [CHAT_CLIENT_LAYERS.md](CHAT_CLIENT_LAYERS.md)。队列批次中途扫描失败后不提前释放仍有POST在途的批次锁；仅stored严格为true且ID匹配才能登记落盘确认，不将写入绑定同步读取的signal。未提供跨页全局串行或恰好一次保证。

## 逐条消息发送状态

- 自己的消息在气泡/分享卡片旁显示小转圈，表示发送中、等待保存确认或等待补发；收到服务器保存确认后隐藏，不把落盘等同对方已读。
- 红色感叹号表示服务器明确拒绝本次请求，或补发达到上限/用户暂停；悬停及消息详情区分拒绝与“未获确认”。超时、暂停和重试耗尽都不证明此前一定未送达。
- 普通发送超时不再设置输入框上方的整段队列错误；队列/回执存储不可读等真正本地故障仍保留错误提示。消息详情保留原目标房间的重试与暂停。
- 失败状态按 scope/消息 ID/接收方保存；已收到回执的记录不被迟到失败覆盖，重试按既有消息 ID 去重。鉴权同步返回的本人消息也可确认服务器已保存，避免 POST 回执丢失后始终转圈；本地归档不作为送达证明。
- 外观、网络中断/恢复、多标签和真实服务拒绝仍待人工验收；构建通过不等于上述场景已验证。

## 导出与旧记录

- `ChatHistoryTools.vue` 仅提供现有分页、导出和失败重试；旧的“备份旧缓存/恢复旧版数据”专用入口已移除，不凭历史文档重加。
- 正常导出合并当前 scope 的数据库记录、待存历史与可见消息；数据库不可读时导出带 `partial: true` 的应急文件，明确不是完整归档。
- 导出包含聊天内容、用户与房间信息，必须由用户妥善保存，不公开分享。历史导出不等于凭证备份，也不保证可直接导入恢复。
- 不自动把未核对作用域的旧 localStorage 消息混入当前房间；有无迁移读取以现行源码为准，不承诺旧缓存能完整找回。

## 边界与验证

- 浏览器清理、扩展卸载、存储回收、配额不足和磁盘损坏可能造成记录丢失，当前没有自动云备份保证。
- 本地历史与服务器 SQLite 不是同一存储；导出本机记录不证明已包含所有服务器历史或所有待发状态。
- 分页、存储失败、导出、多标签及真实消息同步仍需获准人工验收。类型/构建通过不能替代这些验收，不执行断言/无头 E2E。

# docs/history/ 历史档案与迁移台账

本目录归档 tab-project-next（原 LogicWeaver / my-newtab）在各历史重构阶段沉淀的迁移台账、阶段性验收报告与已退役方案记录。

> **读者指引**：
> - **普通使用者与新用户**：请参阅根目录 [README.md](../../README.md)。
> - **日常开发与现行真实入口**：请参阅 [docs/CURRENT_STATE.md](../CURRENT_STATE.md)。
> - **当前模块与组件现行索引**：请参阅 [docs/MODULE_INDEX.md](../MODULE_INDEX.md)。
> - **本目录下的文件仅作为演进历史考证**：其中提及的旧命令、退役脚本、旧测试用例或阶段性未完成状态**不代表当前系统的功能与约束**，禁止据此恢复已删除代码。

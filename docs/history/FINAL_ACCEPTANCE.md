## 二、本次新改动专项验收项（请重点人工复核）

请在 **独立 Edge 配置文件** 中加载目录：
`D:\default save place\GitHub\tab-project-next\dist-extension\v2.3.0-kTWEJl\extension`

### 1. 彻底解决首次打开自动播放
- [ ] 打开新标签页时，控制台无外部 B 站音频/视频网络请求，绝不自动响起 Never Gonna Give You Up。
- [ ] 打开「工作台」：原梯度下降/demo-bili-1 已不再预置。即使历史上有视频聚焦，也只显示「播放此视频」按钮；点击后才加载播放器，切走工作台即销毁。

### 2. Alt+E 与 Alt+Q 轮盘过滤
- [ ] 按 `Alt+E` 打开导航轮盘：没有启用的组件不出现在轮盘扇区中。
- [ ] 打开工具轮盘：不再显示任务架子、预约、云盘、系统监控等已退役或未注册项目；仅显示商店中已注册且当前启用的独立模块。
- [ ] 在商店中开启/关闭模块后，再次呼出轮盘，扇区动态更新，点击不可用项不会报错。

### 3. 快捷键设置分类与修复
- [ ] 打开「设置 → 快捷键」：
  - 界面按「导航与界面」和「已启用组件」清晰分组；
  - 已停用的组件不会在列表中占位；
  - 点击按键槽进入录制模式，按 `Esc` 可安全取消录制；
  - 点击「×」真正清空快捷键绑定（保存为空，不再自动变回默认快捷键）；
  - 点击「↺」单独恢复默认绑定；
  - 录制快捷键时，不会误触发底层的固定操作（如 Alt+W、Alt+H、Ctrl+K）。

### 4. 聊天室实验性与默认关闭验证
- [ ] 首次安装或新配置下，Dock 栏默认**不显示**聊天室图标。
- [ ] 打开「商店 → 独立模块」：海狸聊天室带有「实验性、默认关闭」标识，点击「全部启用」也不会开启它，必须手动逐项启用。
- [ ] 聊天室停用状态下：
  - 不发起任何后台长轮询或网络同步；
  - 常用网站与卡片的「发送到聊天室」菜单自动隐藏；
  - 重新启用聊天室后，之前保存的配置与聊天记录完整保留。

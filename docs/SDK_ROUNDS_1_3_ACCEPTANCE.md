# SDK前三轮：用户操作验收

> 以下是对应轮次的用户回归步骤，不是助手现在应自动执行的任务。入口/模块可能随后变更，先看 [CURRENT_STATE.md](CURRENT_STATE.md)；真实改名、改址或刷新仍由用户决定，旧验收反馈不能覆盖当前所有版本。

前三轮用户已反馈“没有问题”，记为用户交互验收通过；不扩展为未执行的存储故障注入、后台alarm或跨全应用事务验证。以下保留操作步骤供回归，不需要开发者工具、终端或查看代码。
可分次完成。找不到某个入口，直接告诉我停在哪一步，不必猜。

## 0. 准备

- 先保存笔记及其他未保存草稿，在首页按F5，让当前页面加载新构建。
- 暂时只用这一个新版首页验收，不同时在其他旧首页修改同一个网站/文件夹。
- 不需要卸载重装、清缓存、退出账号，也不需要填写任何Token或Client ID。
- 普通F5验证的是页面改动，不证明旧后台worker/定时任务已升级。频道后台停止迁移需之后单独确认，不能仅看入口消失就宣布全部后台验收完成。
- 下面临时改名会真实保存名称；记住原名，测完按相同步骤改回。不改网址，不删除网站或文件夹。

## 1. 网站标题：取消与中文输入（先不保存）

1. 在首页“常用网站”随便选一个网站，右键 → 重命名。
2. 看菜单顶部：应直接变成原样式输入框，文字自动选中，不弹浏览器prompt。
3. 输入几个字，按Esc。
4. 应恢复原名。点击外面再打开该菜单，原名仍在。
5. 再次编辑，使用中文输入法输入拼音，在候选状态下确认文字。
6. 确认候选字不应被误当作整个标题保存；最后按Esc退出本次检查。

通过：没有prompt、Esc确实取消、中文输入不突然结束编辑。

## 2. 网站标题：保存与刷新

1. 记住一个网站的原名，将它临时改成“临时验收”，按Enter。
2. 正常会短暂显示“保存中…”然后“已保存”；本地保存很快，看不到中间状态也正常。
3. 名称更新后，点击菜单外面关闭，F5刷新首页。
4. 应仍显示“临时验收”，网站地址、所属文件夹和排列位置不应因为改名改变。
5. 按同样步骤改回原名，再刷新确认。

可再试一次：编辑临时名称后按Tab离开输入框，应触发保存。一次即可，不必连续敲Enter。

通过：刷新后名字还在，改名不误改网址或位置。

## 3. 错误提示：无需破坏数据

### 网站空名称（必做）
1. 右键网站 → 重命名，把输入框清空，按Enter。
2. 应显示“网站名称不能为空”，输入框保留，不把网站真正改成空名。
3. 输入一个有效的临时名称再按Enter，应能正常保存；之后改回原名。
4. 或直接按Esc取消，原名不变。

### 文件夹重名（有两个自建文件夹才做，没有可跳过）
1. 记住两个文件夹的名称A和B。选自建文件夹，不是默认“常用网站”分组。
2. 右键A → 重命名收藏夹，输入B的原名 → Enter。
3. 应提示已有同名文件夹，并保留输入框供修改。
4. A的真实名称不变，两个文件夹不合并、网站数量不变。
5. 按Esc取消。再打开A，确认名称和里面的网站还在。

错误后点击菜单外部不会立即丢弃这份草稿；可以修改后再次按Enter，或Esc明确取消。
主动切换目标/关闭窗口会结束该次编辑；草稿不是持久恢复功能。

不必断网、禁用存储或填满磁盘。存储写入失败/回读失败分支本次只做源码检查，不能用以上校验错误代替真实存储故障验收。
若实际看到“保存结果未确认”，不要连点：复制草稿、保存其他工作后刷新，先核对当前名称，再决定是否修改。本页会暂停继续标题写入，没有自动重试。

## 4. 文件夹窗口标题（有自建文件夹才做）

1. 打开一个自建文件夹，点击窗口顶部的文件夹名称。
2. 临时改成“文件夹验收” → Enter。
3. 名称应更新，文件夹中的网站保留，窗口不应意外切到别的文件夹。
4. 关闭再打开该文件夹，名称应一致；改回原名。
5. 文件夹名称最多20个字符，输入框与保存规则一致。
6. 如愿意，再从右键菜单改一次并恢复，确认两个入口一致。

通过：窗口标题和文件夹本身一致，没有只改表面标题的假成功。

## 5. dock菜单（不执行任何菜单动作）

1. 右键dock里的todoist或github图标。
2. 菜单应完整显示，不跑出屏幕；将浏览器窗口稍微缩小，再看一次。
3. 按Esc，菜单应关闭。
4. 再打开，点击菜单外空白处，也应关闭。
5. 不点击“退出”“停止”“停用”“重载”，不启动或停止任何原生进程；旧 QQ 模块也不是当前验收入口。

通过：定位正常，Esc和外部点击可关闭，没有多余遮罩。

## 6. 图片与设置（第一轮回归）

### 图片
1. 从dock进入github插件，打开一个有README图片的仓库详情。
2. 等图片加载后点击它。
3. 应打开原来的图片查看浮窗；试滚轮缩放、拖动画布和拖动标题栏，再关闭。
4. 有另一张图片时，可以换图，确认不会跳回上一次的图。
5. 不必点击复制、下载或保存到笔记。没有图片的仓库换一个；图片网络加载失败请单独记录。

### todoist设置
1. 从dock进入todoist，点击右上角设置。
2. 面板应是非模态，后面界面没有被全屏模糊遮挡。
3. 应能找到“Google 日历 OAuth Client ID”配置区。
4. 只看入口，不填、不保存、不截图暴露已有配置，然后关闭面板。

### 频道与主题（顺手看看）
- dock和商店不再出现旧频道模块，AI HOT仍保留。
- 当前主题下图片、菜单、输入框和状态文字清晰。愿意的话切一次明亮或Lonetrail再看，测完恢复原主题。
- 看不到频道入口不等于后台历史alarm已验证删除。

## 第四轮：网址编辑（新增，待验收）

前三轮不必全部再测。保存其他工作、F5刷新首页后：
1. 右键一个网站 → “编辑”（或点菜单里的网址），输入框应就地编辑。输入几个字符再Esc，应恢复原网址。
2. 再编辑，把网址清空 → Enter，应提示“网址不能为空”，草稿保留，原网址不变。Esc取消。
3. 有可修改的测试网站时，先记下完整原网址；临时改成一个HTTP/HTTPS地址，Enter显示“已保存”后刷新，再右键查看是否保留；不要点击网站跳转，最后改回原网址。
4. 标题、备注、文件夹与排列不应被网址编辑带着改掉。保存不访问网址、不检测网络可达性；格式合法不等于网站可用。
5. 非HTTP/HTTPS协议以及含用户名/密码的网址会被拒绝。不要输入真实凭据来测试。

备注菜单编辑的残留代码已删除，并没有删除已有备注数据；CLI仍使用原saveLinkNote方法，此入口未在本轮改写或执行。

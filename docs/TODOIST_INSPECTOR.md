# Todoist 任务详情（本地改造，待人工验收）

- 标题完整换行并按内容高度增长；描述查看时排版、点击后原位无边框编辑，失焦触发原有草稿保存，保留图片粘贴。未改变 Todoist 的文本保存目标。
- `todoist-inspector.css` 只负责正文；`inspector-window.css` 负责窗口，替换旧样式堆叠。日期、标签、优先级和提醒使用同一个原生 Popover 浮层容器，不通过极大 z-index 或全屏遮罩遮住页面。
- 标签选择读取完整 `/labels`，创建调用标签 API，再关联任务；写入中禁止连续勾选，失败保留错误并提示核对。
- 日期面板的时间使用可手输的 AM/PM 输入和每15分钟推荐列表；兼容24小时输入，手输不限制15分钟（如11:07 PM）。Enter/失焦确认、方向键选推荐、Esc收起；12:00 AM保存为00:00，12:00 PM保存为12:00。仍向既有保存链路提交HH:mm，不新增云端时间语义。
- 提醒 UI 由 `ReminderPicker.vue` 提供快捷延迟、嵌入日历、AM/PM 时间、预览和保存错误提示，替换原生 datetime-local。共享时间选择器仍有15分钟推荐，可输入任意分钟；无效时间不提交。通知权限失败保留窗口，不假称已保存。
- 本机提醒使用 `chrome.storage.local` 的逐任务键和 alarms。兼容读取旧 map，触发成功写入完成标记；后台启动恢复闹钟。前台不再读取另一套 localStorage 副本。浏览器关闭/系统休眠可能延迟；不承诺定点或跨设备通知，系统仍可能抑制通知。
- 评论上方的关联仓库卡片由 `TaskRepositoryLinks.vue` 保存本机任务对应的仓库快照，不写任务描述、不调用 Todoist API、不恢复已删除的工作台。支持搜索当前插件已加载的仓库或粘贴 owner/repo / GitHub 地址。未加载仓库只保存链接，不伪造统计或在线抓取。资料是关联时快照，不自动更新；当前不支持拖拽搬运、跨设备同步。
- 任务日历将“今日日程/待办”合为按所选日期显示的任务列表，未完成任务与已完成记录共享一个列表。优先取任务“日期”（既有本机开始日期），无日期时取 Todoist 截止日期；不展开跨天区间、不预测未来重复实例。具体时刻按本机时区展示；取消日期后回退截止日期，二者都无则不列入某一天。
- Todoist 侧栏不读取 Google 日程或连接状态，初始化和切月不启动 Google 授权/联网；保留独立日历模块的既有 Google 实现，不删除凭据或缓存。日期格标记来自任务，切日立即切换投影，提交期间中止旧读取，提交结束后刷新；隐藏/卸载停止读取，无后台轮询。主动任务按游标分页，单次最多100页，超限或重复游标报错、不接受部分列表。完成历史使用 `/api/v1/tasks/completed/by_completion_date`，按所选日的本机零点换算 UTC 范围，读取 `items` 与 `next_cursor`，每页最多200条、最多100页，不再使用 Sync v9 的 `completed/get_all`。端点及字段依据 Doist 官方 SDK 的 `src/clients/task-client.ts`、`src/types/tasks/requests.ts` 核对（https://github.com/Doist/todoist-api-typescript）。历史失败不阻断待办显示，允许手动重试并区分401/403，不假称已经验证真实接口或权限。
- GitHub 仓库详情“任务”创建栏与分组“设为 GitHub 任务区”已接入，真实创建任务并复用本机关联卡片存储，写入/失败边界和人工验收清单见 [GITHUB_TASKS.md](GITHUB_TASKS.md)。
- 开发仅运行类型检查、构建、差异和后台语法检查；未启动浏览器、未调用真实账户接口、未执行系统通知验收，未提交或发布。视觉及真实标签/提醒需用户重新加载扩展后验收。

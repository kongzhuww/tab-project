# v1.0.10 发行说明

- **版本**：1.0.10
- **发布日期**：2026-11-03
- **构建环境**：Windows 11 / Node.js 22 / Chromium MV3
- **主要焦点**：快捷导航轮盘交互全线升级、Todoist 弹窗全面无模态与自由拖拽改造、主题与外观移入设置面板、确立“默认无模态”全局铁律。

---

## 核心变更

### 1. 快捷导航轮盘（NavWheel）革命性交互升级
- **中心自由拖拽（Draggable Hub）**：按住轮盘正中央圆盘即可在屏幕任意位置自由拖拽移动，轻松避开后方图标与内容；原地微距点击（<4px）仍灵敏响应返回上层或收起。
- **点选即入盘（Pick to Wheel）**：进入「✏️ 编辑网站」管理模式后，无需繁琐勾选确认，点击桌面常用网站或文件夹内网站，**当场直接加入轮盘并实时生成扇区**；桌面对应网站点亮专属绿色 `✓` 徽标。
- **即时移出与红叉管理**：再次点击已入盘网站（或直接点击轮盘扇区右上角的红色 `✕`）即可当场将其从轮盘移出；点击「✅ 完成编辑」纯粹作为优雅收尾，红叉与标记即刻隐去。

### 2. Todoist 弹窗全面无模态与自由拖拽改造
- **彻底告别全屏暗化模态**：全面清除 `.todoist-dialog-overlay` 灰黑遮罩与模糊层，背景 100% 保持原始明亮与通透，绝不遮挡用户视线或阻断其它区域浏览。
- **100% 实体纯白不透光工艺纸面**：弹窗卡片本体强制采用实心纯色背景（明亮模式实心纯白 `#ffffff`，暗黑模式实心深色 `#1e293b`），彻底解决半透明磨砂把底色透上来导致弹窗发灰发暗的视觉顽疾。
- **按钮下方精准智能锚定**：点击「重命名」或「删除项目」时，弹窗自动紧贴在被触发按钮的正下方展开，并自带视口边缘智能防溢出。
- **标题栏支持拖拽移动与 Click-Outside 收起**：弹窗头部配备抓取手柄 `⋮⋮`，用户可随手按住头部拖拽到屏幕任意角落；点击弹窗卡片外部任意空白或按 `Esc` 键均可就地快速收起。

### 3. 主题设置优化与顶栏回归纯净
- **顶栏右上角轮转按钮移除**：移除主界面顶栏右上角突兀的主题轮转按钮，顶栏视野回归纯净、开阔、对称，避免误触。
- **设置 04 升级为「主题与外观」**：设置面板原“壁纸与背景”升级为「04 主题与外观」（面板大标题为“主题与外观定制”）。
- **首位集成系统主题风格卡片组**：提供白天明亮、夜间深色、终末地、孤星四套主题的微缩窗口预览卡片，支持实时点击切换、高亮状态标记与浅色模式推荐指引。

### 4. 规范确立：默认无模态铁律（Modeless by Default）
- 在仓库与全局 `AGENTS.md` 中白纸黑字正式确立：除非用户有明确要求，所有弹窗、确认框、输入框与卡片默认一律为无模态，严禁全屏灰黑蒙版，严禁半透明发灰发乌，保证界面清爽通透。

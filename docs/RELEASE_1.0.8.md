# tab-project v1.0.8

### 覆盖式侧栏
- 新标签页与普通 HTTP(S) 网页统一使用右侧无模态覆盖侧栏，不再缩窄网页视口；支持扩展图标、Alt+W、× 和 Esc。
- 外网页仅在用户触发时注入隔离容器，复用扩展 iframe 内的侧栏界面；关闭后移除容器与监听，不常驻注入所有网站。
- 移除浏览器原生侧栏注册与 sidePanel 权限；受保护页面提示不支持，不回退到挤压式侧栏。
- 修正侧栏消息通道、目标标签页路由、透明背景与关闭后的焦点可达性。
- 修复 Todoist 跨页面同步在后台无条件访问 window/document，导致 Service Worker 注册失败、快捷键处理不生效的问题。

### GitHub 原生 Lists
- 收藏分类改为以 GitHub 官方 Lists 为准，支持同一仓库归属多个 List，新增列表与仓库归属管理及本地读取缓存。
- 移除“正在使用”特殊分类；旧本地分类不自动上传、迁移或纳入云备份，仓库备注继续保留。
- GitHub Lists 写操作需要相应 Token 权限；权限不足时显示提示，不代表所有 Token 都能写入。

### B站收藏搜索
- 输入后按回车或搜索按钮执行检索；清空搜索词时恢复收藏夹列表。

### 验证与发布边界
- 通过 Windows 类型检查、Vite/后台构建与隔离发行构建；未运行断言或无头 E2E。
- 用户授权下在 Edge 正式扩展/B站网页实际验证侧栏图标、Alt+W、×、Esc，网页宽度保持不变，侧栏外的搜索框仍可点击聚焦。
- 未宣称 GitHub Lists 全部真实账号写入、所有网站或所有主题均已验收。
- GitHub Release 不等于 Edge 商店更新；现有解压安装用户需更新文件并重新加载扩展。

## 安装

下载本发行页的 `tab-project-v1.0.8-extension.zip`，解压后在 Edge/Chrome 扩展管理页选择“加载解压缩的扩展”。更新已有安装时先备份设置，替换原扩展目录文件后重新加载；不要把源码 ZIP 当作可直接加载的发行包。

附件同时提供 `SHA256SUMS.txt` 和 `build-info.json`。发行 ZIP 在根目录放置 manifest.json，由 GitHub Actions 隔离构建，不包含开发目录中遗留的历史 chunks。

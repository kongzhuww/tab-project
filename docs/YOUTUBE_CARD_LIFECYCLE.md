# YouTube 卡片生命周期：入口与推荐读取

## 已实施：入口按需加载与设置保活

- 首页首次选择daily-youtube且showYouTube开启才挂载卡片，随后保活。View使用useCardActivity，异步组件迟到挂载或页面隐藏时不启动首次读取；独立youtube.html保留。
- 删除fullscreen宿主进入YouTube时的init/loadUpdates。当前卡片只展示个性推荐/本地收藏，订阅更新写入的是另一份videos状态，原来这条入口额外读取RSS却不展示。
- init仍由卡片首次可见时执行，保留收藏读取；移除没有当前UI消费者的频道列表预热。订阅/频道方法保留，未删除订阅数据或其他兼容功能。
- 信息立方体等实际目标元素挂载登记后再Teleport，卸载按身份注销。
- 设置面板首次点击才创建、关闭/切卡片后保留草稿，visible控制Teleport隐藏与定位监听。初次读取有版本/可见保护和串行重试；未读好不允许保存。
- 已提交设置保存不因隐藏撤销；保存返回时若面板隐藏或不是推荐页，不再启动新的推荐刷新，提示返回推荐页手动刷新。整页关闭仍不保证草稿恢复。

## 第二阶段：推荐与翻页读取会话

- View按卡片可见/推荐tab创建AbortSignal，隐藏、换收藏tab、卸载使旧scope失效；首次/切回空推荐或中断恢复可读取，已结束失败不因单纯焦点恢复自动重试。页面动作使用scope，CLI显式load-recommend使用独立signal，状态读取不变。
- loadRecommend/追加推荐共享单个有代次的读取槽：新推荐取消旧读，追加读取中拒绝重复追加；signal、generation检查覆盖配置/缓存/后台消息/网络/body/持久化返回后的UI写回。45秒总上限，超时明确提示。
- read-request.ts提供有限时、可取消等待的后台消息及覆盖body的直接fetch。取消后台消息只解除本页等待，不承诺worker实际请求停止；不改后台鉴权或读取Cookie。
- 推荐解析器不再写公共continuation token。每次读取持有私有token，成功且仍有效才提交；同步喜欢/稍后观看等仅解析视频，不再污染推荐token。预取最多三批、重复token检测；追加失败保留原token供显式重试。
- RSS备用通道接收父signal，取消后不再发直接抓取回退。直接fetch可Abort，已发后台消息及缓存持久化不能物理撤回。跨页缓存与已经提交的存储仍非原子事务。
- View追加后的自动翻页核对页面版本/可见性/tab/原页码，迟到结果不滚动或跳页。设置保存不把中断读取伪报成更新成功。

## 第三阶段：收藏与同步写入门禁

- 新增favorites-storage.ts，仅读取原youtubeFavoritesV1/youtubeFavGroupsV1。Chrome callback检查runtime.lastError，localStorage读写/解析失败不吞；非数组/异常分组拒绝覆盖。只对收藏启用严格存储，不把旧服务所有存储语义一起改掉。
- 收藏新增/移出、分组增删、喜欢/稍后观看同步共用同页互斥门禁，重复调用拒绝，不排队自动重试。固定视频与增删意图；改副本后一次提交列表和分组，重新读取核对后再更新内存/展示，不提前乐观改心形。
- 初次收藏读取共用Promise/版本，写操作使旧读取失效；刷新/重读不与写入竞争。读取、收藏写入各有状态，不再借用推荐isLoading互相覆盖。
- 保存错误或回读不一致进入needsReview，保留旧展示并禁用后续写，显式重读成功后才恢复。写提交前失败与提交后未确认分别提示，不宣称失败已经回滚。
- 同步页面读取有15秒含body上限，隐藏不撤回显式同步工作流。网络返回后再读一次最新收藏合并，按视频ID去重，不清空用户收藏；只报告本次页面可解析结果，不声称账户完整同步。
- 反馈改卡片内非模态状态，移除成功/失败appDialog弹窗；隐藏后的结果保留供回来查看，不强制换tab/跳页。删除导致当前收藏页越界时，仅活跃收藏页收敛页码。
- 已发存储、跨页或跨设备竞争仍非事务，readback只证明核对当时内容；localStorage两键可能部分写入。未引入跨页锁，也未实际运行收藏读写。

## 剩余边界

这不是YouTube全部生命周期迁移完成：
- 服务init的动作监听仍为页面级；未全面治理旧订阅/搜索/播放列表读取。主动CLI读取独立于卡片可见性，仍可更新共享展示；新推荐读取会取代旧推荐读取，并非多个独立结果仓库。
- 已发后台请求、缓存存储不能保证撤销；窗口关闭后不继续解析/回退/提交本轮读取结果，不等于整个worker停机。
- 收藏写入门禁仅覆盖当前服务实例；整页关闭、跨标签/恢复备份/其他写入者没有事务保障，远端喜欢列表只有当前页面可解析部分，不改远端点赞。
- CLI与全局兼容服务仍是现行消费者，不能不检查就删除服务方法或把所有请求都绑定到View可见性。
- 服务仍经globals/CLI静态导入，因此这里只保证卡片初始化按需，不宣称所有YouTube代码离开首包、所有后台工作已停止或实测性能提升。

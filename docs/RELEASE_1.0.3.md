# tab-project-next v1.0.3

本次更新聚焦仓库关联任务、B站播放与评论、文章阅读以及通知目标。

## 更新内容

### GitHub / Todoist
- 仓库右侧任务栏在创建表单上方显示关联的未完成任务，多张卡片纵向滚动。
- 左侧圆圈独立完成任务，正文点击打开插件内任务详情。确认完成后隐藏，保留仓库关联；结果未确认不自动重试。循环任务推进后的下一次实例可能重新出现。
- 兼容 Todoist 新版 checked 与旧 is_completed 字段，修正已完成任务刷新后仍留在关联列表的问题。
- GitHub 普通读取进度和错误统一放在顶部标题旁；AI付费任务核对和停止操作继续保留。

### B站
- 磁带收起后播放、暂停及切歌不再触发自动展开，只有明确展开按钮才展开。
- 小窗评论与楼中楼显示图片，点击使用共享图片查看器，独立B站页同时接入。
- 播放器与剧场通知保存对应BV/AV，点击打开目标视频，不再统一跳到消息中心；真正私信/回复/提及汇总仍打开消息面板。
- 修复通知选项透传与空BV误判同一视频。旧通知若没有保留视频编号或唯一合法链接，无法可靠恢复原视频目标。

### ai hot阅读
- 复制和原文入口使用主题适配按钮与线框图标，保留已复制反馈。
- 优先提取真正正文，排除源站桌面/手机版重复控件、重复导读及推荐区。
- 新版正文缓存键避开旧错误提取，不删除其他缓存和个人数据。

## 下载与升级

下载附件 **tab-project-v1.0.3-extension.zip**，不要使用 GitHub 自动生成的 Source code 压缩包作为扩展安装包。

升级前备份重要数据。沿用原扩展目录与浏览器资料更新文件，再由用户在扩展管理页重新加载，并刷新已打开的新标签页及独立模块页面。不要为升级随意卸载扩展或清除浏览器数据，以免丢失本地记录与授权。

另附 SHA256SUMS.txt 与 build-info.json，用于校验文件和构建来源。GitHub发布不会自动提交Edge商店；商店安装用户需等待另行提交、审核和分发。

# tab-project-next v1.0.5

本次更新聚焦 GitHub 快捷频道全新「我的仓库 · Topic 看板」工作区、双向拖拽与远端 Topics 自动同步、边缘自动滚动与滚轮横向联动、原生右键级联移动菜单系统、防压缩卡片布局及多项交互细节优化。

## 更新内容

### GitHub 工作区全新「我的仓库 · Topic 看板」
- **左侧快捷频道新入口**：新增「📦 我的仓库」专属通道（副标题：个人项目 · Topic 看板，徽标：REPOS），秒级切入个人项目全景看板。
- **Todoist 风格横向看板布局**：
  - **左侧第一列「默认板块」**：集中收拢未打任何 Topic 标签或未归类项目，充当待分类全量池；
  - **右侧各列「#Topic 分组」**：自动读取并聚合 GitHub 远端已有的 Topics 标签，支持一键新建 Topic 板块、重命名 Topic 并同步所有相关仓库，以及删除板块。

### 双向拖拽与 GitHub Topics 远端自动同步
- **自由拖拽归类**：
  - 将卡片拖入右侧任一 Topic 列，自动为该项目打上对应标签，并通过 GitHub REST API（`PUT /repos/{owner}/{repo}/topics`）秒级同步至远端；
  - 将卡片拖回左侧「默认板块」，自动从该 Topic 移出并同步远端；
  - 各列之间自由拖拽自动更新对应 Topic 归属。
- **轻量拖拽动效**：拖动卡片时半透明虚线框跟随，目标列激活科技蓝外发光反馈，松手即落，无破坏性跳动。

### 视口横向滚动交互体验
- **Shift + 鼠标滚轮**：在看板任意位置按住 Shift 滚动鼠标滚轮，看板平滑左右滑动；
- **拖拽中直接滚动滚轮**：拖拽卡片过程中全局接管滚轮，无需按键直接滚动鼠标滚轮即可平滑左右滑动看板，轻松跨越多个分组；
- **触边自动滚动（Edge Auto-scroll）**：拖拽卡片靠近看板左右边缘 100px 范围内时，看板自动向对应方向加速滚动，移开即停。

### 原生右键级联菜单系统
- **卡片就地右键菜单**：右键任意卡片弹出原生菜单，边界自动计算防出界；
- **多级飞出子菜单（`📁 移动到分组 ›`）**：
  - 悬停或点击立即向右展开二级子菜单（靠屏幕右边缘时自动向左翻转）；
  - 支持一键「设为未分类（移入默认板块）」，或直达特定 Topic，已有分类高亮蓝勾标注；
- **快捷复制与跳转**：支持「📋 复制仓库链接」带 Toast 反馈、「💻 复制克隆命令」与「↗ 在 GitHub 打开」。

### 界面与工程质量
- **卡片高度防挤压**：为卡片增加 `flex-shrink: 0`，项目数量较多时卡片保持饱满舒展高度，彻底消除多项目下的纵向压缩变形；
- **主题规范适配**：纯纯基于系统 CSS 变量（`var(--panel)`、`var(--surface)`、`var(--text)` 等）设计，全自适应明亮、暗色与 Lonetrail 纸面主题。

## 下载与升级

下载附件 **tab-project-v1.0.5-extension.zip**，不要使用 GitHub 自动生成的 Source code 压缩包作为扩展安装包。

升级前备份重要数据。沿用原扩展目录与浏览器资料更新文件，再由用户在扩展管理页重新加载，并刷新已打开的新标签页及独立模块页面。不要为升级随意卸载扩展或清除浏览器数据，以免丢失本地记录与授权。

另附 SHA256SUMS.txt 与 build-info.json，用于校验文件和构建来源。GitHub 发布不会自动提交 Edge / Chrome 商店；商店安装用户需等待另行提交、审核和分发。

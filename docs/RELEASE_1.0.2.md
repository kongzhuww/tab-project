# tab-project-next v1.0.2

本次更新移除开发调试通道，开发版与发行版保持一致。

## 变更

- 删除内建 CLI/Broker、页面和后台的调试长轮询及任意 JavaScript 调试执行入口。
- 删除 Jev 扩展协作桥接、页面观察与操作适配器。
- 移除专用 CLI 脚本、npm 命令和不可达的旧调试构建块，更新维护规范。
- 保留正常业务功能及用户数据，不清空配置、书签、聊天或本地文件。

## 下载与升级

请下载附件 **tab-project-v1.0.2-extension.zip**，不要使用 GitHub 自动生成的 Source code 压缩包作为扩展安装包。

升级前备份重要数据。在保持原扩展目录和浏览器资料的前提下更新文件，再由用户在扩展管理页刷新，并刷新已打开的新标签页或独立模块页面。不要为了升级随意卸载扩展；卸载或清除浏览器数据可能导致本地记录丢失。

附件另含 SHA256SUMS.txt 和 build-info.json，供校验下载完整性与构建来源。

## 验证边界

已进行类型检查、构建、隔离发布构建和调试标记静态核对。没有进行真实浏览器交互验收或商店审核；构建通过不等于完整安全审计。

壁纸沙箱及用户导入 HTML/JS 的能力本次未修改，不能据此直接宣称“无远程代码”。第三方账号、服务授权及数据处理方式仍按各功能说明和隐私政策执行。

# 性能热点复核与本轮优化

本轮是源码层面的风险消减，不是性能跑分报告。没有运行浏览器调试、断言或无头 E2E；不能由构建成功推断掉帧已消失。

## 原清单第 3–10 项

| 项目 | 核实结果及处理 |
| --- | --- |
| 常用网站图标 | 组件和 launcherService 原先分别转换 Canvas，且组件重复同步写入位图。删除组件侧的重复转换和位图写入，复用服务已有的异步扩展存储；兼容读取旧缓存。成功源缓存移到真正的共享 TS 模块并限长，已加载源不重复转换。 |
| b站插件列表 | `BiliFavorites.css` 已有 `content-visibility: auto`、固有高度及菜单展开例外，之前遗漏了这一事实。本轮不重复添加，不直接替换成虚拟网格，以免破坏批量选择、拖放和菜单。DOM 数量与 Vue 更新开销仍存在，是否需要虚拟化应由长列表实际表现决定。 |
| obsdian模块编辑 | 源码编辑与预览原本是互斥显示，隐藏预览却仍会解析全文。现在编辑时只保存原始草稿；回到预览时解析最新内容。不修改保存时机，不按段切分 Markdown，以免破坏跨段语法。 |
| 毛玻璃 | dock 已是 12px，不需要再次缩减。桌宠快捷栏从 24px 降为 12px，保留饱和度和主题。未批量添加永久 `will-change`，因为额外合成层可能增加显存成本。降低半径不等于耗时减半。 |
| 常用网站拖拽 | Pointer Move 合并到每个动画帧处理最新坐标；同一次命中只读取一次目标矩形，读取早于目标样式写入。松手消费最终位置，取消/卸载清理帧任务，忽略其他指针。不永久缓存几何坐标，因为换位动画、滚动和切分区会令其失效。 |
| 聊天历史 | 屏幕外消息使用 `content-visibility: auto` 与记忆高度，获得布局/绘制跳过；聚焦消息保持可见。保留全部历史节点和分页功能。这不是 Vue Diff 跳过，也不是完整虚拟列表；未加入依赖不完整的 `v-memo`，避免头像、发送状态或一起听按钮不更新。 |
| 滚动立方体 | 隐藏音乐面不再挂载，隐藏自定义面的正文不渲染；倒数日只在当前面启用计时，切入时立即刷新。保留滚轮、键盘和右键切面能力，不强制切回音乐面。上一轮仅简化了音乐内容，并没有把 3D 立方体变为单层平面。 |
| 歌单 JSON | 两个现有网易云缓存键共用解析缓存，未变化的数据复用解析结果；写入合并延后 250ms，离页刷新，退出登录取消待写并移除缓存，跨标签页 storage 事件使缓存失效。保留旧格式，不迁移用户数据。首次 JSON 解析、延后执行的序列化和 localStorage 本身仍是同步操作，并非 IndexedDB 异步迁移。 |

## 验证与边界

- 质量门禁：`npm run check`、`node --check generated/background.js`、`git diff --check`。
- 没有新增依赖，没有修改服务器、版本号或发布流程。
- 未量化 CPU、GPU、帧率或交互延迟收益。
- 页面突然崩溃可能丢失最后 250ms 尚未写入的可重建歌单缓存，不涉及聊天室历史或笔记草稿。pagehide 刷新不是崩溃持久性保证。
- 聊天采用估计高度；图片完成解码与历史节点首次进入视口时的滚动锚定仍需界面验收。

## 建议人工验收

1. 刷新扩展后检查常用网站图标和自定义图标；拖拽换位、跨分区、移入文件夹及取消拖拽。
2. 长笔记连续输入，保存后切回预览；切换立方体各个面，检查音乐与倒数日。
3. 长聊天记录翻页/滚动、图片加载、消息详情和一起听状态；网易云缓存重开、双标签页同步与退出登录。

按项目约束不自动操作浏览器。若实际仍卡顿，先定位具体操作，再决定是否引入完整虚拟化或异步存储迁移，不把它们当作无条件优化。
